# Дача Фибоначчи — Android widget build

This branch contains a base64-split ZIP archive of the Android project under `chunks/part-*`. The GitHub Actions workflow reconstructs the archive, builds a debug APK, and uploads it as the `dacha-fibonacci-widget-apk` artifact.

The project contains only application code and empty/demo data. It does not contain real guest records, phone numbers, finances, or the user's working database.
