# Sync v2

Рабочая область внедрения манифеста офлайн-first синхронизации.

## Этапы

1. Зафиксировать фактический исходник версии 0.10.3.
2. Добавить надёжное хранение входящих отложенных изменений и tombstone.
3. Исключить потерю удалённых/пропущенных изменений при продвижении серверного курсора.
4. Заменить автоматический last-write-wins для критичных полей на полевое объединение и явные конфликты.
5. Добавить восстановление очереди, backoff и подробную диагностику.
6. Обновить Apps Script и тесты протокола для 5+ устройств.
7. Провести сценарные тесты длительного офлайна и одновременной работы.

Текущая рабочая APK 0.10.3 остаётся неизменной до выпуска отдельной тестовой сборки sync v2.
